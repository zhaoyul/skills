# Resume/checkpoint policy

Before continuing a long translation, verify all three:

1. `.translation/state.json` last source locator;
2. last stable content in the Org file;
3. the corresponding source page/spine item.

Continue only when they agree. If they disagree, reconcile before writing new translated content.

Checkpoint after each chapter or natural subsection. Never cut a checkpoint inside a sentence, footnote, code block, table or caption.
