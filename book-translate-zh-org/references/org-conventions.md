# Org conventions

- Simplified Chinese.
- ASCII punctuation in Chinese prose.
- Images: `[[file:images/...]]`.
- Only add `#+CAPTION:` when a real source caption exists.
- Inline math: `\(...\)`.
- Display math: `\begin{equation} ... \notag \end{equation}` when the source has no equation number.
- Never use `\[...\]`.
- Code: `#+begin_src LANGUAGE`.
- Literal output: `#+begin_example`.
- Quotations: `#+begin_quote`.
- Footnotes: `[fn:id]` plus matching definition.
- Preserve irregular source numbering instead of silently renumbering.
